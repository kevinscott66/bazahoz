# GeoField — прототип экрана сбора пробы

Flutter-каркас и экран **регистрации пробы** (ТЗ §6.5) поверх схемы из
`geofield/core/schema`. Цель прототипа — «проверить ощущение в руке и на холоде»
(шаг 15.4 мастер-плана): дизайн-токены, режим перчаток, автосохранение,
семантические цвета типов проб, генерация штрихкода/QR.

## Что демонстрирует

- **Дизайн-система** (ТЗ §4.3) — свои токены (`lib/theme/tokens.dart`), тёмная
  тема, единственный янтарный акцент, моноширинные цифры, шкала отступов 4–8–12–16–24.
- **Семантика типов проб** (ТЗ §4.3) — устойчивый цвет типа на плитке и на бирке
  (`lib/theme/sample_type.dart`).
- **Автосохранение** (ТЗ §0, принцип 2) — проба пишется в базу сразу при открытии
  (черновик не теряется) и при каждом изменении с дебаунсом. Каждая мутация —
  строка в `samples` + запись в `change_log` (event sourcing, `sync-protocol.md`).
- **Режим перчаток** (ТЗ §4.5) — тумблер в шапке: крупнее цели, двойное
  подтверждение удаления.
- **Бирка** — «Показать код» рисует настоящий QR; «Печать бирки» за выключенным
  флагом честно сообщает об отсутствии принтера (см. `UNFINISHED.md`).

## Запуск

Нужен Flutter SDK (>= 3.19) — в этом окружении его нет, проверяется на машине с тулчейном:

```bash
cd geofield/app
flutter pub get
flutter run             # телефон/эмулятор
flutter run -d linux    # или macos / windows — десктоп через sqflite_common_ffi
flutter test            # юнит-тесты (util/sample_number)
flutter analyze         # статанализ
```

## Статус проверки

- Логика номера пробы (`SampleNumberTemplate`) — алгоритм проверен отдельно, есть
  юнит-тест `test/sample_number_test.dart`.
- SQL прототипа — подмножество `001_initial.sql`, полная схема проверена
  применением в sqlite.
- **Компиляция Flutter в этом окружении не выполнялась** (нет Dart/Flutter).
  Перед мержем: `flutter pub get && flutter analyze && flutter test` на машине с SDK,
  прогон экрана на реальном телефоне (холод, перчатки) — это и есть смысл шага 15.4.

## Структура

```
lib/
├── main.dart                         точка входа, демо-проект, запуск экрана 6.5
├── config/features.dart              feature-флаги (барьер заглушек)
├── theme/tokens.dart                 дизайн-токены
├── theme/sample_type.dart            типы проб + семантические цвета
├── models/sample.dart               модель пробы (== таблица samples)
├── util/sample_number.dart           генерация номера по схеме проекта
├── data/database.dart                открытие SQLite (WAL) + миграция-подмножество
├── data/sample_repository.dart       upsert пробы + журнал изменений (транзакция)
└── screens/sample_capture_screen.dart  экран регистрации пробы (ТЗ 6.5)
```
